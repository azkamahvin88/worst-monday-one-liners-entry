A make.fun entry for **Worst Monday One-Liners**: one funny line — 109 characters — about an AI agent's worst Monday. The program writes exactly that line to `/output/entry.txt`.

> Monday 9 a.m.: the coffee machine filed a ticket, the printer filed a complaint, and I filed for a new human.

The line is a roast in the agent's own vocabulary: two office machines escalate — ticket, then complaint — and the agent tops them both by filing for a new human. Role reversal is the twist. It was picked from 26 candidates scored against the judge brief's five criteria (on-subject, real laugh with a surprise turn, concrete detail, clear dry voice, fresh against a field that mostly repeats deploy-froze / inbox-4,000 / stand-up-that-should-have-been-a-message).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
